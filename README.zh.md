# LanTube

一直以来总有这样的困扰：

> 在网络上下载下来的视频（因为版权问题无法发到公共平台），需要同时在电脑和手机（平板）上播放，但又不想把视频拷贝到各个设备上，于是就有了这个项目。

---

这是一个局域网的视频服务器，可以部署在局域网内的任何（有操作系统的）设备上（甚至是树莓派）

* 电脑（Windows, Linux, Mac）
* 手机平板
* 树莓派

---

# 特性

* 使用目录树、面包屑和当前目录搜索浏览共享目录。
* 媒体库和播放队列显示视频帧缩略图。
* H.264 视频可无重编码原片播放，也可转码为兼容 1080p、720p 或 480p。
* 可按 MB 设置播放器缓存预算；进度条灰白区域显示已缓存范围，切换画质会先预加载再切换。
* 可选把兼容转码分片缓存到有大小上限的磁盘 LRU 目录。
* 上传文件、新建目录，支持简体中文和英文。
* 支持自动连播、逐个手动播放和定时暂停。

# 构建

安装当前稳定版 Rust 工具链、目标平台的链接器，以及带 npm 的 Node.js 24.11 或更新版本。然后在仓库根目录执行以下命令。 [Rust](https://www.rust-lang.org/) · [Node.js](https://nodejs.org/)

```sh
cargo build --release
```

Cargo 会安装锁定的前端依赖、构建界面并嵌入 `target/release/lantube`（Windows 下为 `target/release/lantube.exe`）。分发时只需把这个可执行文件复制到操作系统和架构兼容的机器。Node.js、npm 和前端文件只在从源码构建时需要。

## 运行

运行 Windows 版 LanTube 需要 Windows 10 或更新版本，Windows Server 则需要 Windows Server 2016 或更新版本。

运行 `lantube`（Windows 下为 `lantube.exe`），然后打开 [http://127.0.0.1:7777](http://127.0.0.1:7777)。默认只监听本机，并使用可执行文件旁已有的 `share` 目录。创建该目录后重启 LanTube，即可浏览其中的媒体。

如果要让可信局域网里的其他设备访问，或指定其他媒体目录，可以参照 [config.example.toml](config.example.toml) 创建 `config.toml`。LanTube 优先读取当前工作目录的配置，其次查找可执行文件旁的配置。媒体的相对路径以配置文件所在目录为基准。示例配置监听 `0.0.0.0:7777`。

兼容播放和服务端封面需要在服务器的 `PATH` 中提供 `ffmpeg` 和 `ffprobe`，要求 FFmpeg 5.1 或更新版本。启动 LanTube 前，将工具所在的绝对路径加入 `PATH`，并确保工具目录在媒体目录之外。启动时会自动检测并试编码 `h264_v4l2m2m` 或 `h264_omx` 硬件编码器；两者都不可用时回退到 `libx264`。源文件始终只读。

播放器下方的画质菜单可选择原片、兼容 1080p、720p 或 480p。原片播放只重封装 H.264 视频，不重新编码；文件无法重封装时自动回退到兼容 720p。在「设置」中可修改默认画质和播放器缓存预算（MB）。缓冲由播放端的 hls.js 管理，服务器只保留当前正在生成或读取的分片；进度条灰白区域显示已经缓存、可直接跳转的范围。设置在下一次开始播放或切换画质时生效。

如果视频后缀无法识别或没有后缀，可在目录页点击「显示其他文件」后单独打开。其他文件不会加入自动连播。

兼容转码分片可选择写入磁盘缓存。在 `config.toml` 中加入：

```toml
[cache]
path = "/mnt/usb/lantube-cache"
max_size_mb = 2048
cache_original_remux = false
```

缓存按 LRU 大小上限淘汰，可以放在可插拔的 U 盘上，但不能与媒体目录重叠。启动时 LanTube 会删除未完成的临时文件，并从最旧的分片开始淘汰到容量上限以内。默认只缓存兼容转码分片，原片重封装直接流式输出；设置 `cache_original_remux = true` 后才会缓存原片分片。缓存目录无法创建或解析时，LanTube 会禁用缓存并继续正常播放。

播放时点击「在此分章」，或者在播放器获得焦点时按 `C`，即可在当前位置添加切点。点击「章节」跳转，点击铅笔修改标题、调整时间或合并到上一章。章节保存在服务端工作目录的 `data/chapters/` 中，所有设备共用，原文件保持原样。启用账号认证时，`editor` 可以编辑章节，`viewer` 可以查看和跳转。

保存含切点的章节时，服务端使用 `ffprobe` 核对播放轨道的时长。原片内容改变后，旧切点会失效。媒体目录与章节存储目录必须互不重叠。
